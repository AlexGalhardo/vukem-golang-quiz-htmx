# Changelog rules

- Keep a Changelog 1.1.0; `[Unreleased]` always exists at the top.
- Sections: Added, Changed, Deprecated, Removed, Fixed, Security.
- SemVer tags `vX.Y.Z`; a release moves `[Unreleased]` into a dated section and pushes the tag (the release workflow does the rest).
- Never edit a released section; never move or delete a pushed tag.
